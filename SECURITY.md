# Segurança

Encontraste uma falha de segurança numa ferramenta? **Não abras uma issue nem uma discussão pública.**

Usa o botão **Report a vulnerability** no separador *Security* do repositório da ferramenta. Fica privado entre ti e nós até estar corrigido.

Agradecemos no CHANGELOG (se quiseres) quando a correção sair.
