# Código de Conduta

Esta comunidade existe para aprender e construir ferramentas que resolvem problemas reais.

- **Respeito.** Critica ideias, nunca pessoas. Toda a gente começou do zero.
- **Sem spam nem vendas.** Não se fazem anúncios nem se pedem dados a ninguém.
- **Privacidade.** Não publiques dados teus nem de outros (IPs, chaves, endereços, nomes).
- **Ajuda a sério.** Se sabes a resposta, partilha-a. Se não sabes, diz o que tentaste.

Quem não cumprir pode ver as mensagens apagadas e ser bloqueado. Para avisar de um problema, fala connosco no Instagram [@kcu.services](https://www.instagram.com/kcu.services).
